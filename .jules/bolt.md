## 2026-08-09 - Three.js Object Library Caching and Cache-Aware Disposal
**Learning:** Re-instantiating similar geometries (BoxGeometry, CylinderGeometry, ConeGeometry) and materials (MeshStandardMaterial) for numerous procedural mockup objects causes high heap churn and increases garbage collection overhead. Simply traversing and disposing of all objects in a Three.js scene works well for temporary worlds, but destroys shared caches if cached items are disposed indiscriminately.
**Action:** Tag shared/cached geometries and materials using `userData = { cached: true }`. Update the scene disposal function to skip disposing tagged cache objects. Provide a separate clearCache function that manages the proper disposal and clearing of cached geometries and materials during component unmounts.
