## 2026-07-21 - Hardware-Accelerated Color Sampling with 1x1 Singleton Canvas
**Learning:** Performing regional average color extraction on HTMLImageElement can be extremely CPU-bound and memory-intensive if done by allocating temporary canvases repeatedly and summing pixel values in JS. Instead, we can create a single 1x1 Offscreen/HTML Canvas, set its `globalCompositeOperation` to `'copy'` (to bypass `clearRect` overhead on redraw), and draw the desired region scaled down to 1x1. The browser's native GPU/rasterizer uses linear filtering to interpolate the entire region down to a single pixel, yielding the average color instantly without any JS loop or GC pressure.
**Action:** Use a 1x1 singleton canvas with lazy initialization (to avoid breaking non-browser or SSR contexts) for fast, hardware-accelerated regional color averaging.
